# Certificate Photos Folder

You can drop your certificate photos / scanned documents into this folder (`public/certificates/`):

1. `data-analytics-python.png` -> Data Analytics with Python (NPTEL)
2. `iot.png` -> Internet of Things (IoT) (NPTEL)
3. `ibm-python.png` -> Python for Data Science (IBM)
4. `infosys-aiml.png` -> AI/ML and Data Science (Infosys Springboard)

Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.pdf`

You can change any file names in `src/data/portfolioData.ts` under the `CERTIFICATIONS` list.
